# Skills Club React Landing Page

A responsive React + Vite landing page based on the provided Skills Club design direction.

## Features
- Responsive desktop, tablet and mobile layouts
- Sticky navigation with mobile menu
- Career clarity hero and event details
- Benefits and 15-day curriculum cards
- Interactive 3-step quiz UI
- Expandable FAQ accordion
- Learner testimonials
- Email newsletter form UI
- Lucide icons and Hindi/Hinglish copy

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Before publishing
- Update the session date/time and confirm current availability.
- Connect the CTA to your real registration form or booking link.
- Replace placeholder testimonials/logos with approved real content.
- Connect newsletter form submission to a backend or email service.
- Confirm privacy policy, terms, certificate and recording details.

## Stack
React, Vite, CSS, lucide-react.
